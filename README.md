 # Airbnb Bangalore Power BI Dashboard

## Project Overview

This project presents an interactive Power BI dashboard for analyzing Airbnb listings in Bangalore.

The dashboard provides insights into listing distribution, pricing, occupancy, guest experience, host performance, property characteristics, and booking patterns.

The objective is to transform Airbnb listing and review data into meaningful business insights through data cleaning, data modeling, DAX calculations, and interactive Power BI visualizations.

##  Project Objectives

- Analyze Airbnb listing distribution across Bangalore
- Understand pricing and revenue-related patterns
- Analyze occupancy and booking trends
- Evaluate guest experience using review data
- Analyze host performance
- Compare different property types
- Identify patterns in Airbnb listings and bookings
- Present insights through an interactive Power BI dashboard

##  Tools & Technologies

- Power BI
- DAX
- Power Query
- CSV / Excel
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization
